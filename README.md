# 中游事件因子检验

读取上游 `event-alpha` 交出的行业因子 JSON，按《中游因子校验提纯入库系统 V2.2》的事件轨道做检验。不改上游分数，不把这批卡片送进日频轨道，也不做行业中性化。

一条因子在窗口结束前只记为未到期。窗口从新闻日的下一交易日到有效期截止日（截止日不是交易日时，停在前一个交易日）。新闻当日涨跌不计入。成份等权收益减去同期沪深 300，绝对值低于 1% 记为未拉开。

同一事件类型、同一申万一级、同一方向，满 8 条已结束的可检验事件，命中率不低于 60%，平均行业超额与信号同号，且该类最近一张卡片的成份说明不是 missing，才标为可下发。不足 8 条保持观察。

样例只核对字段。成份说明为 missing 或成份为空时不编造股票、不计算收益。二级没有公开指数时仍检验一级篮子。

```bash
PYTHONPATH=src ../.venv/bin/python -m factor_check \
  --factors ../event-alpha/out/industry/factors \
  --out out \
  --as-of 2026-11-17
```

档案写在 `out/audits.jsonl` 和 `out/summary.json`。窗口已经结束的卡片，用前复权收盘价和沪深 300 计算超额；窗口未结束时不拉行情。日频轨道仍留在 V2.1，当前没有输入，这里不实现。调度不放在这个包里。
